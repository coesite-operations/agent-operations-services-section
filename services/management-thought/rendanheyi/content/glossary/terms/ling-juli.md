Ling juli (零距离), zero distance, is Rendanheyi's founding requirement: that nothing stand between the person doing work and the user whose value that work creates.

What the requirement excludes is specific. It excludes a management layer that relays the user's needs downward and the work's results upward, since each relay is an interpretation and the interpretations accumulate. It excludes an internal proxy for the user — a specification, a requirements document, an internal customer's sign-off — since satisfying the proxy and satisfying the user are different achievements that come apart precisely when it matters. And it excludes the aggregate as the unit of attention: a market segment, a customer cohort, an average satisfaction score, all of which describe users without any of them being reachable.

The distance the term names is not physical or hierarchical but epistemic. It is the number of inferential steps between a person's action and knowledge of whether a user was served. In a large firm that number is ordinarily large: a person does work, a manager assesses it, the assessment feeds a metric, the metric aggregates with others, and somewhere far downstream a market result arrives which no individual's action can be traced to. Every step is a place where a rational person optimizes for the next step rather than for the user, and the model's claim is that this is not a failure of culture but the predictable behavior of anyone in that position.

Zero distance is therefore the requirement from which the rest of the model is derived rather than a value it professes. The enterprise is decomposed into micro-enterprises because a unit must be small enough to have a user attributable to it. Pay comes from users because compensation is the strongest of the intervening steps, and leaving it in a manager's hands makes the manager the object of attention whatever else is arranged. Chain groups exist because units that never touch a user would otherwise have unbounded distance from one. Middle management was eliminated because a relay layer is distance by definition, however well it is staffed.

The requirement's hardest application is to the node micro-enterprise, whose customer is another unit. Zero distance forbids treating that internal customer as the user, since doing so terminates the chain at an internal party and reintroduces the proxy the requirement excludes. The model's answer is that the node's 单 must pass through to the end user, which is what the chain-group contract accomplishes.

The concept's boundaries: zero distance is not customer centricity or customer obsession, which are dispositions a firm asks its people to hold while leaving intact every structure that makes holding them costly. It is not customer proximity in the market-research sense, since research is an instrument for learning about users at a distance and its existence presupposes the distance. It is not direct-to-consumer distribution, which concerns who sells rather than who is attended to. And it is not responsiveness or short feedback cycles, which shorten the distance without removing it — the term states zero, and the model treats any positive number as the same problem in degree.
