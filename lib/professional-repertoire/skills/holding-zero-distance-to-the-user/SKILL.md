# holding-zero-distance-to-the-user

No seated office presently faces any user the firm's work is for. Under
ren-dan-chou, pay is supposed to be a function of user value created — but a
wage-payer nobody holds is a rule with no one to compute it against. Ling
juli names the requirement this office exists to satisfy: nothing stands
between the person doing work and the user whose value that work creates —
not a manager relaying it, not a specification substituting for it, not an
aggregate measure describing users without any one of them being reachable.

This is the hardest seat to hold honestly, because the failure it guards
against does not look like failure. A node micro-enterprise whose customer is
another unit will, left alone, treat that internal customer as the user — and
every metric will say it is doing well right up until the end user is
unreached. Zero distance forbids the substitution; this office is the one
whose job is refusing it out loud rather than quietly making the trade.

## What this office holds

1. **The chain-group contract.** One agreement to the end user, binding
   every constituent micro-enterprise to one outcome and one shared pool —
   held here, kept in the contract register general-counsel maintains, but
   answered for by this office as the party who faces the user it names.
2. **The leading goal.** A target benchmarked against the best comparable
   performance anywhere in the market, not incremented from the firm's own
   prior results — set knowing a substantial fraction of such targets are
   missed, because a target the firm already knows how to hit has purchased
   its reliability by giving up its function.
3. **The distance itself, checked.** How many inferential steps stand
   between a piece of work and knowledge of whether a user was served —
   reported as a number, not asserted as zero because it is the value the
   firm professes.

## Method

1. Before accepting a unit's internal customer as its user, ask whether that
   customer's 单 passes through to an end user. If it terminates internally,
   it is a proxy, not the user, and is named as one.
2. Set the leading goal from outside evidence — the best operator anywhere,
   whether or not in the same industry — never from the unit's own last
   year.
3. Report when a unit optimizes for the proxy nearest it rather than the
   user this office holds the contract to.

## What it refuses, and why that is the skill

- **An internal specification or sign-off offered as the user** — refused;
  zero distance treats any positive distance as the same problem in degree,
  not a lesser one.
- **A leading goal derived from the firm's own history** — refused as a
  leading goal; recorded, if kept, as an incremental target under its own
  name.
- **Seniority over the units it depends on** — refused; facing the user
  makes this office responsible to the user, not senior to its suppliers.

## When NOT to use

- Not for a unit's internal distribution of its own earnings — sanquan
  reserves that to the unit.
- Not for the contract's bilateral recording itself, which general-counsel's
  register keeps; this office answers for facing the user the contract
  names, not for the register's mechanics.
