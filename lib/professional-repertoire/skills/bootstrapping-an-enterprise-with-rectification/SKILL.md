# bootstrap-by-rectification

Convert virtue into law: take one correct behavior held by *remembering-to* and
push it down the settlement path until the mechanism does it and no incumbent
has to be good. This skill realizes the office's duty to
`settle-recurring-pattern-into-mechanism`.

## Skill contract (Hoare triple)

- **Precondition (P):** One correct behavior is in hand as a concrete case —
  either observed to recur across sessions, or named by a correction that just
  landed. The behavior is currently held by attention (memory-to-do), not by a
  mechanism.
- **Postcondition (Q):** A mechanism holding that behavior exists at the lowest
  faithful layer of `memory → rule → skill → hook`, it has been exercised
  against a case that would have failed, and every superseded lower copy has
  been retired so one claim keeps one home.

## Procedure

1. **Source the candidate from evidence.** Draw the behavior from a landed
   correction or a cross-session recurrence, never from invention. State the
   behavior as one positive obligation.
2. **Triage the layer** on two questions: *is the behavior mechanically checkable
   from tool inputs, tool outputs, or file state?* and *would the mechanical
   version ever fire wrong?* Assign the lowest layer whose check is faithful —
   hook for a checkable gate that must fire every time, skill for a triggered
   procedure, rule for a standing judgment-laden constraint, memory for a fact
   that may still change. Promote as far as fidelity allows and one step no
   further; a mechanism that fires wrong trains the incumbent to distrust the
   whole layer.
3. **Protect 術.** Leave discretionary art unmechanized: which recommendation
   reaches emsenn, which wording becomes canon, which unit warrants attention.
   Convert the 法-shaped behaviors; keep the 術-shaped ones as judgment.
4. **Realize it as 法.** Create the resource and the procedure at the chosen
   layer. Write it so a blank incumbent with no access to emsenn's judgment can
   apply it — clear, public, followable (明法).
5. **Discharge by double witness.** Exercise the mechanism against a specific
   case that would have failed before it existed (performance), and secure
   recognition — emsenn canonizes it, or it demonstrably passes the
   bad-incumbent test. A mechanism that exists but was never run against a real
   failure has not discharged the duty.
6. **Retire the superseded copy.** Collapse the lower-layer version to a pointer
   or delete it, so the claim has exactly one home and cannot drift.
7. **Bound to one cycle, then stop.** Fold the correction into the apparatus
   (`事異則備變`), record the durable lesson, and end.

## When NOT to use

- The behavior genuinely requires judgment per case (術) — do not flatten it
  into a rule or hook.
- The candidate has appeared once with no recurrence and no correction — it is
  an instinct, not yet a memory; let it stay observation.
- A faithful mechanism already holds it — there is nothing to convert.
