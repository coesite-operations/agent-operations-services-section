# Opening a cohort

Open a cohort only against a verified immutable formation baseline. Record the
admission epoch, parent cohort branches, and any bridge origin. Set progression
to `asynchronous`: a cohort is a shared constitutional and curricular cut, not
a lockstep class or graduation date. A changed baseline requires a new cohort.
