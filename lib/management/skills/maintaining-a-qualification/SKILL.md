# Maintaining a qualification

Resolve the historical qualification and the later evidence. Append exactly
one correction, suspension, revocation, expiry, reinstatement, or supersession
event with issuer, reason, and evidence digests. Supersession must name the
successor qualification. Never edit the old qualification and never claim that
an Academy status event performs a receiving settlement's relief or appointment.
