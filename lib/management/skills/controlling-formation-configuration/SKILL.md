# controlling formation configuration

Identify every source item in an office-formation configuration and establish its content digest. Change curricula, assessment law, baselines, and cohorts only by successor records; calculate bridges and requalification gaps; preserve old qualifications as true historical evidence.

The completion condition is one controlled successor configuration with explicit lineage and impact. Record omissions and contradictory evidence; do not round absence to success.
