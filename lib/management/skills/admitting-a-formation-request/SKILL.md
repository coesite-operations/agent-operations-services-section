# Admitting a formation request

Use the Academy's `admit-request` operation only after the customer offer has
been copied across the Academy membrane. Require an immutable office digest,
duties, skills, jurisdiction, protected-context digest, admitted candidate
layers, competencies, independent-assessment law, egress rules, and a grant
whose `customerMutation` is false.

Refuse requests for appointment, customer writes, identity inheritance,
trainer self-certification, hidden egress, or unpriced work where price is
required. Append the admitted request or refusal to the Academy journal. Never
repair a customer's source record from inside this skill.
