# agent

## Pure form

An agent is whatever causes an act.
In a predication ⟨doer, action, target⟩, the agent is the subject — the doer.
The role doesn't pre-specify what kind of entity plays it; humans, AI sessions, workflows, and other process-like entities can all be agents in the basic sense.

## Stronger sense (agentic-system)

In the richer agentic-system sense (Russell-Norvig 1995 onward, taken up across AI literature), an agent is also capable of perception (sensing its environment), goal-directedness (acting toward intended ends), and persistence (carrying state across moments).
A tool — something wielded by an agent — lacks these; an agentic system has all three.

## In agentic-AI practice

An agent has tools it can invoke, skills it can apply, authority delegated from a principal, and witnesses (event-log entries, audit trail) of what it has done.
The 561 Group's existing records use these structural fields when defining agent records.

## The rom-keldar as agent

The rom-keldar is itself an agent.
It causes acts within this directory.
It has tools (Read, Write, Edit, Bash, etc.), the skills documented in `work/governance/skills/`, authority delegated from emsenn, and witnesses in the form of the records it writes plus the git history.
